# 08. 오디오 시스템 (TTS, SFX, 립싱크)

## 핵심 원칙

외형은 프롬프트로 폴백해도 시청자가 참을 수 있지만, **목소리가 매 화마다 바뀌면 바로 어색하다**. 따라서 음성은 에셋 등록 시점에 즉시 고정한다.

## 음성 배정 시점

| 시점 | 동작 |
|------|------|
| 1단계 (대본 입력) | 에셋 등록 시 음성 풀에서 자동 매칭 |
| 4단계 (에피소드 중 즉석 등장) | 신규 에셋 등록과 동시에 음성 배정 |

외형(LoRA)과 달리 음성은 **지연 없이 즉시 확정**된다.

## 음성 타입

| audio_type | 대상 | 음성 |
|------------|------|------|
| TTS | 캐릭터, NPC, 말하는 몬스터 | voice_id (예: voice_m_husky_01) |
| SFX | 아이템, 몬스터, 환경 | 효과음 파일 (예: sfx_shadow_wolf_growl_01) |
| NONE | 장소 등 소리 없는 에셋 | 없음 |

## 음성 풀 (voice_pool)

사용 가능한 TTS 음성 목록. 각 음성에 태그가 붙어 있다.

```
voice_m_husky_01:    남성, 20-30대, 낮음, 건조
voice_m_warm_03:     남성, 40-50대, 중음, 따뜻
voice_f_clear_02:    여성, 20대, 높음, 또렷
voice_f_low_01:      여성, 30대, 중저음, 차분
voice_child_01:      어린이, 중성
...
```

## 자동 매칭 로직

1. LLM이 에셋 추출 시 `voice_hint` 출력 (예: "20대 남성, 낮고 건조한 톤")
2. 시스템이 voice_hint의 키워드를 voice_pool 태그와 매칭
3. 후보 중 프로젝트 내 미사용 음성 우선 선택

## 중복 검사

- 프로젝트 안에서만 적용 (다른 프로젝트와는 무관)
- 주요 캐릭터끼리 같은 음성 사용 금지
- 단역 NPC끼리는 공유 허용, 단 **같은 씬에 동시 등장하는 경우 제외**
- 사용자가 자동 배정 결과를 수동으로 변경 가능

## TTS 생성 타이밍

```
스토리보드 리뷰 중  → TTS 생성하지 않음 (대사가 수시로 바뀔 수 있으므로)
                    → 개별 대사 "TTS 미리듣기" 가능 (임시 파일)
에피소드 확정 후     → TTS 일괄 생성 (확정된 대사만)
```

### TTS 미리듣기

- 스토리보드 리뷰 중 특정 대사 옆 "TTS 미리듣기" 버튼
- 해당 대사 1줄만 TTS로 생성하여 재생
- 임시 파일. 확정 후 일괄 생성 시 다시 만듦

### TTS 일괄 생성

에피소드 확정 시 실행:
1. 모든 대사를 순회
2. 각 대사의 `tts_voice_id` + `emotion` 태그로 음성 파일 생성
3. `dialogues.tts_file_path`에 파일 경로 기록

## 음성 길이 검증

TTS 생성 후 각 대사의 음성 길이를 해당 샷의 `duration_sec`과 비교.

- 음성 길이 > duration_sec → 경고
- 선택지: 대사를 줄이거나, 장면 길이를 늘림
- 모든 경고 해결 후 Export JSON 조립으로 진행

## 립싱크

- 립싱크 데이터 생성은 Story Engine 범위가 아님 (Video Factory/Wan 2.2 측에서 처리)
- Story Engine은 `apply_lipsync: true` 플래그와 TTS 파일 경로만 Export JSON에 포함
- Video Factory가 TTS 음성 파일을 받아 립싱크 노드에서 처리

## 효과음 (SFX)

- 에셋에 고유 효과음이 등록된 경우 (예: 혈석검 → sfx_crystal_pulse_01)
- 오토 바인딩 시 해당 에셋이 등장하는 샷의 sfx 배열에 자동 삽입
- 등록되지 않은 환경음/분위기음은 LLM이 샷 생성 시 sfx 필드에 무드 기반 태그로 지정

## BGM

- 샷 단위로 `bgm_mood` 태그 지정 (예: "dark orchestral tension", "lighter folk undertone")
- 에피소드 단위 `overall_mood`도 별도 존재
- 구체적인 BGM 파일 매핑은 Video Factory 측 처리 또는 추후 BGM 라이브러리 연동
