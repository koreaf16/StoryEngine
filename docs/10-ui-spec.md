# 10. UI 명세

## 전체 화면 구조

시스템은 단일 페이지 앱(SPA)으로 두 가지 레이아웃을 사용한다.

### 프로젝트 목록 (`/`)

사이드바 없이 전체 폭 레이아웃.

```
┌──────────────────────────────────────────┐
│ TopNav: Story Engine | Projects          │
├──────────────────────────────────────────┤
│                                          │
│          프로젝트 카드 그리드              │
│                                          │
├──────────────────────────────────────────┤
│ Footer                                   │
└──────────────────────────────────────────┘
```

### 프로젝트 내부 (`/project/:id/*`)

프로젝트를 선택한 뒤에 좌측 사이드바(4단계 네비게이션)가 나타난다.

```
┌──────────────────────────────────────────┐
│ TopNav: Story Engine | Projects          │
├───────────┬──────────────────────────────┤
│ Sidebar   │                              │
│ ─────     │                              │
│ Script  ◀ │       메인 컨텐츠             │
│ Character │                              │
│ Visual    │                              │
│ Episode   │                              │
│           │                              │
│ Plan Card │                              │
└───────────┴──────────────────────────────┘
```

사이드바 활성 항목은 현재 URL 경로에 따라 자동 판별된다:
- Script: `/seed`, `/prompt-a`, `/paste-a`, `/prompt-b`, `/assets`
- Character: `/characters`
- Visual: `/visual`
- Episode: `/episode`

## 화면 목록

### 0. 프로젝트 목록

**진입**: 시스템 접속 시 첫 화면

**구성**:
- 프로젝트 카드 그리드 (2열)
- 각 카드: 제목, 장르 태그, 에피소드 수, 에셋 수, 마지막 작업일, 상태 뱃지
- "새 프로젝트" 카드 (점선 테두리)

**동작**:
- 카드 클릭 → 해당 프로젝트 진입
- 새 프로젝트 → 제목 입력 → 1단계로

---

### 1-a. 씨앗 입력

**구성**:
- 안내 텍스트: "머릿속에 있는 이야기를 자유롭게 적어주세요"
- 텍스트 영역 (자유 형식, 최소 높이 200px)
- "프롬프트 생성 →" 버튼

---

### 1-b. 프롬프트 A (세계관 뼈대)

**구성**:
- 안내: "아래 프롬프트를 복사해서 외부 LLM에 붙여넣으세요"
- 프롬프트 박스 (모노스페이스, 읽기 전용, 배경색 구분)
- "복사" 버튼
- "응답 붙여넣기 →" 버튼

---

### 1-c. 응답 붙여넣기 (Pass 1)

**구성**:
- 안내: "LLM 응답을 아래에 붙여넣으세요"
- 붙여넣기 영역 (점선 테두리, 드롭존 스타일)
- 미리보기 영역 (붙여넣은 후 포맷팅해서 표시)
- "저장하고 프롬프트 B 생성 →" 버튼

---

### 1-d. 프롬프트 B (에셋 추출)

**구성**: 1-b와 동일 레이아웃. 프롬프트 내용만 다름 (JSON 추출 지시).

---

### 1-e. 에셋 확정

**구성**:
- 에셋 목록 (행 레이아웃)
  - 각 행: 아바타(첫 글자) + 표시명 + 타입 뱃지 + 시각 전략 + 음성 ID
  - "수정" 버튼 (인라인 편집)
- "+ 에셋 추가" 버튼
- "확정하고 다음 단계로 →" 버튼

**에셋 타입별 뱃지 색상**:
- 캐릭터: teal
- NPC: purple
- 장소: blue
- 아이템: coral
- 몬스터: gray

---

### 2-a. 캐릭터 목록

**구성**:
- TTS 타입 에셋만 필터링하여 카드 형태로 표시
- 각 카드: 아바타 + 이름 + 타입 + 프로필 상태 (미설정/AUTO/확정)
- 카드 클릭 → 2-b로
- "건너뛰고 에피소드로 →" 버튼

---

### 2-b. 캐릭터 프롬프트 C

**구성**:
- 상단 탭: "LLM으로 생성" / "직접 입력"
- LLM 생성 선택 시: 프롬프트 C 표시 + 복사/붙여넣기 UI
- 직접 입력 선택 시: 자유 텍스트 영역

---

### 2-c. 캐릭터 프로필 확정

**구성**:
- 캐릭터 헤더: 아바타 + 이름 + 타입 + 음성 ID + 시각 전략
- 섹션별 프로필 표시:
  - 성격 (본문)
  - 말투 (본문 + 말버릇 태그)
  - 과거 (본문)
  - 행동 규칙 (태그 나열)
- "수정" / "확정 →" 버튼

---

### 3-a. 외형 공장 — 에셋 선택

**구성**:
- 전체 에셋 목록 (타입 필터 가능)
- 각 행: 이름 + 타입 + 현재 시각 전략 (PROMPT/LORA 뱃지)
- 에셋 클릭 → 3-b로
- "건너뛰고 에피소드로 →" 버튼

---

### 3-b. 앵커 선택

**구성**:
- 앵커 생성 방식 선택: "텍스트 기반 (Flux)" / "사진 업로드 (PuLID)"
- appearance_prompt 표시 (편집 가능)
- 후보 이미지 그리드 (4열)
  - 각 이미지: 품질 등급 뱃지 (S/A/B/C)
  - 선택된 이미지: 초록 테두리 + "선택됨" 뱃지
- "다시 생성" / "앵커 확정 →" 버튼

---

### 3-c. 파생 + 필터

**구성**:
- 진행률 바 (12/15 완료 등)
- 요약: "완료: N / 통과: N / 탈락: N"
- 카테고리별 이미지 그리드:
  - 얼굴 클로즈업 섹션
  - 상반신 섹션
- 각 이미지: 프리셋 이름 + 거리 수치 + 통과/탈락 뱃지
- 탈락 이미지는 반투명 처리
- 필터 기준 표시: "거리 0.4 초과 시 탈락, 측면은 필터 제외"
- "LoRA 학습 시작 →" 버튼

---

### 3-d. LoRA 완료

**구성**:
- 완료 체크 아이콘
- 요약 정보: 학습 이미지 수, 트리거 워드, 파일명
- "다른 에셋 작업" / "에피소드 만들기 →" 버튼

---

### 4-a. 에피소드 시작

**구성**:
- 에피소드 번호 표시 + 이전 에피소드 유무 상태
- 힌트 입력 영역 (비워두면 자동)
- 컨텍스트 요약 박스: 방향타 요약 + 캐릭터 상태 + 기억 상태
- "프롬프트 생성 →" 버튼

---

### 4-b. 골격/씬 프롬프트

**구성**:
- 상단 탭: "골격 (D)" / "씬 1 샷 (E)" / "씬 2 샷 (E)" / ...
  - 완료된 탭은 체크 표시
  - 미진행 탭은 비활성
- 프롬프트 박스 + 복사 버튼
- 응답 붙여넣기 영역
- 신규 에셋 감지 시: 노란 알림 바 ("npc_harbormaster 자동 등록됩니다")
- "전체 씬 완료 → 스냅 생성" 버튼

---

### 4-c. 스토리보드

**구성**:
- 씬별 그룹핑
- 각 씬 헤더: "씬 1: 비레 항구 도착"
- 샷 카드 (2열: 스냅 이미지 | 상세 정보)
  - 스냅 이미지 (140px 너비)
  - 상세:
    - 샷 번호 + 장면 설명
    - 태그: 카메라 모션, 길이, 전환 효과
    - BGM 태그
    - SFX 목록
    - 대사 블록 (있는 경우):
      - 화자명 (색상 구분) + voice_id
      - 대사 텍스트 + 감정 태그
    - 바인딩 뱃지: "LoRA: kai_char" 또는 "PROMPT: borok"
  - 버튼: "수정" / "스냅 재생성" / "TTS 미리듣기" (대사 있는 경우) / "삭제"

**편집 기능**:
- 샷 순서 드래그 변경
- 대사 인라인 편집
- 카메라/전환/길이 드롭다운 변경
- 샷 추가/삭제

**상단 액션**:
- "씬 추가"
- "에피소드 확정"

---

### 4-d. 확정 + TTS

**구성**:
- 처리 단계 카드 (세로 목록):
  1. TTS 일괄 생성 (진행률 또는 완료 뱃지)
  2. 음성 길이 검증 (경고 건수, 해결 버튼)
  3. Export JSON 조립 (대기/진행/완료)
  4. 세계 상태 갱신 (대기/진행/완료)

- 경고 해결 UI:
  - "Shot N: 대사 5.8초 → 장면 4초"
  - "대사 줄이기" / "장면 6초로 변경" 버튼

- 완료 후:
  - "스토리보드로 돌아가기"
  - "에피소드 N+1 시작 →" 버튼

## 공통 UI 패턴

### 프롬프트 복사/붙여넣기 루프

모든 LLM 연동 화면에서 반복되는 패턴:

```
┌─────────────────────────────────┐
│ [프롬프트 제목]      [복사 버튼] │
│                                 │
│ (모노스페이스 프롬프트 텍스트)    │
│                                 │
├─────────────────────────────────┤
│ ┌ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐  │
│   여기에 LLM 응답 붙여넣기      │
│ └ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘  │
│                      [제출 →]   │
└─────────────────────────────────┘
```

### 에셋 상태 뱃지

| 상태 | 색상 | 텍스트 |
|------|------|--------|
| PROMPT | gray | PROMPT |
| LORA | teal | LORA |
| 캐릭터 | teal | 캐릭터 |
| NPC | purple | NPC |
| 장소 | blue | 장소 |
| 아이템 | coral | 아이템 |
| 몬스터 | gray | 몬스터 |

### 진행 바

4단계 진행 바. 각 단계:
- 미진행: 회색 텍스트, 회색 하단선
- 진행 중: 검정 텍스트, 검정 하단선, 볼드
- 완료: 회색 텍스트, 초록 하단선
