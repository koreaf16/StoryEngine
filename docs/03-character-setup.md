# 03. 2단계: 캐릭터 잡기

## 목적

에셋 목록에서 캐릭터/NPC/몬스터를 선택하여 성격, 말투, 과거사, 행동 규칙을 설정한다. 이 프로필이 에피소드 생성 시 LLM 프롬프트에 직접 포함되어 대사와 행동의 일관성을 만든다.

## 대상

audio_type이 TTS인 에셋, 즉 말을 하는 존재들이 주 대상이다. 캐릭터, NPC, (말하는) 몬스터.

## 진입

1단계(에셋 확정) 완료 후, 캐릭터 타입 에셋 목록이 표시된다. 사용자가 설정할 캐릭터를 선택한다.

- 주요 캐릭터만 하면 됨
- 건너뛸 수 있음 (나중에 해도 됨, LLM이 알아서 채워서 사용)
- 에피소드 진행 중 언제든 돌아와서 추가 설정 가능

## 설정 방식 (택일)

### 방식 A: LLM 협업 생성

시스템이 프롬프트 C를 생성한다.

```
다음 세계관에서 캐릭터 '{캐릭터명}'의 상세 프로필을 작성해라.

포함할 항목:
- personality: 핵심 성격, 감정 표현 방식, 약한 부분
- speech_style: 문장 길이, 말버릇, 톤, 존댓말 여부
- backstory: 핵심 상처, 욕구, 두려움
- behavioral_rules: 절대 하지 않는 것, 특정 상황 반응

JSON으로 출력해라.

=== {캐릭터명} 기본 정보 ===
{에셋 등록 시의 기본 정보}
=== 세계관 맥락 ===
{방향타 내용}
```

사용자가 복사 → LLM → 응답 붙여넣기. 시스템이 파싱하여 프로필을 표시한다.

### 방식 B: 사용자 직접 입력

사용자가 자유 형식으로 캐릭터 정보를 적는다.

```
카이:
- 말수가 적고 단문으로 말한다
- 감정을 숨기려 하지만 눈빛에서 드러난다
- "...그래" 같은 말줄임이 습관
- 술은 안 마신다
```

시스템이 이를 구조화된 프로필 형식으로 정리하여 저장한다. (내부적으로 LLM 프롬프트를 생성하여 구조화할 수도 있고, 사용자가 직접 JSON을 편집할 수도 있음)

## 캐릭터 프로필 데이터 구조

```json
{
  "asset_id": "char_kai",
  "profile_status": "CONFIRMED",
  "personality": {
    "core_trait": "과묵하고 자기 억제적",
    "emotional_pattern": "감정을 숨기려 하나 눈빛으로 드러남",
    "soft_spot": "어린아이, 약자"
  },
  "speech_style": {
    "sentence_length": "극단적 단문",
    "habit_phrases": ["...그래", "됐어", "알아서 해"],
    "tone": "낮고 건조, 감정 절제",
    "speech_level": "반말 기본, 어르신에게만 존댓말"
  },
  "backstory": {
    "wound": "과거에 지키지 못한 사람이 있다",
    "desire": "속죄, 그러나 방법을 모른다",
    "fear": "또 누군가를 잃는 것"
  },
  "behavioral_rules": [
    "절대 술을 마시지 않는다",
    "전투 중에는 말을 하지 않는다",
    "거짓말을 하지 못한다 (침묵으로 회피)"
  ]
}
```

## profile_status

| 상태 | 의미 |
|------|------|
| NONE | 프로필 미설정. LLM이 기본 정보만으로 대사 생성 |
| AUTO | 에피소드 중 즉석 등장한 캐릭터에 LLM이 자동 생성한 임시 프로필 |
| CONFIRMED | 사용자가 직접 확인/수정한 확정 프로필 |

AUTO 프로필은 컨텍스트에 "이 캐릭터의 성격은 아직 확정되지 않았으니 기존 묘사와 일관되게 유지하되 유연하게 해라"라는 주석과 함께 들어간다.

## 에피소드 중 즉석 등장 캐릭터

에피소드 4단계에서 LLM이 새 캐릭터를 만들면 두 가지 선택지:

- **즉시 심화**: "세라라는 새 캐릭터가 등장합니다. 설정을 지금 잡으시겠습니까?" → 2단계 프로세스 진행
- **지연 심화**: LLM이 첫 등장 맥락으로 임시 프로필(AUTO) 자동 생성. 나중에 사용자가 수정 가능

## 캐릭터 외 에셋의 심화

장소, 아이템, 몬스터도 필요하면 심화 가능하나 범위가 다르다.

- **장소**: 분위기, 시간대별 변화, 소리 환경
- **아이템**: 능력, 부작용, 발동 조건
- **몬스터**: 행동 패턴, 약점, 서식지

이것들은 1단계(에셋 추출) 시 LLM이 세계관 규칙에 맞춰 기본값을 함께 생성하고, 사용자가 확인만 하면 충분하다.

## UI 흐름

1. 캐릭터 목록 화면: TTS 에셋만 필터링하여 표시. 각 항목에 프로필 상태 표시
2. 캐릭터 선택 → "LLM으로 생성" / "직접 입력" 택일
3. LLM 생성 선택 시: 프롬프트 C 표시 → 복사/붙여넣기 루프
4. 결과 표시: 성격, 말투, 과거, 행동 규칙을 섹션별로 표시
5. 수정/확정 버튼
